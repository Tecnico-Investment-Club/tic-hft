# TIC-HFT

**TIC-HFT** is a high-performance, multi-threaded crypto trading engine written in C++ for the Binance exchange. Designed for low-latency execution, the system implements a modular architecture where market data is ingested via WebSockets and distributed through a thread-safe data bus to parallel strategy units (Trading Pods)
